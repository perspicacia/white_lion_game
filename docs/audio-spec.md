# SNOWCUB RUN — 오디오 규격

## 1. 원칙

- 외부 음원과 상용 음악을 사용하지 않습니다. 모든 배경음·효과음은 Web Audio API의 오실레이터와 자체 생성 노이즈로 즉시 합성합니다.
- BGM은 인카/안데스 연상의 분위기만 참고하고, 기존 게임·가수의 멜로디·리듬·샘플을 복제하지 않습니다.
- 소리는 반드시 사용자의 `게임 시작` 클릭/터치 안에서 `AudioContext` 생성 및 `resume()`를 실행합니다. 그 전에는 소리를 시작하지 않습니다.
- `AudioContext.state === "suspended"`이면 점프·공격·터치 입력 시 한 번 더 `resume()`합니다. 이 절차가 모바일에서 소리가 안 나는 문제를 막습니다.

## 2. 버스와 음량

```text
musicBus (-18 dB) ─┐
                   ├─ compressor ─ master (-8 dB) ─ destination
sfxBus   (-11 dB) ─┘
```

- 마스터 슬라이더는 0~100% 로 표시하고, 실제 gain은 선형 대신 제곱 곡선 `gain = (value / 100) ** 2`를 사용합니다.
- 공격·피격·보스 소리가 재생될 때 BGM을 80~180ms 동안 3dB 줄였다 되돌립니다.
- 음소거 버튼은 BGM과 효과음을 함께 제어하되, 설정의 음량 값은 별도로 보존합니다.
- 일시정지 시 BGM은 120ms 페이드아웃, 계속하기 시 180ms 페이드인합니다.

## 3. 오리지널 BGM

- 템포: `112 BPM`, 4/4, 16분음표 스텝 스케줄러.
- 조성: A minor pentatonic(A-C-D-E-G). 두 마디 멜로디를 8마디 단위로 변주합니다.
- 베이스: A2-A2-C3-A2-D3-C3-G2-A2, square wave, 90~170ms, -24dB.
- 리드: triangle wave 220~659Hz, 짧은 벤드 ±3 cent, -21dB. 기존 작품의 멜로디를 따라하지 않습니다.
- 타악: 105→42Hz sine kick, 1850Hz band-pass noise rattle. 1·3박은 낮은 북, 2·4박은 마라카스 강세.
- 스테이지별 변주: 1단계는 열린 리드, 2단계는 low-pass 2400Hz와 리버브 8%, 3단계는 타악 약간 증가와 베이스 옥타브 보강. BPM과 판정 타이밍은 같게 유지합니다.
- 스케줄링은 80ms마다 실행하고 280ms 앞까지 노트를 예약해 화면 프레임 드롭에도 리듬이 끊기지 않게 합니다.

## 4. 효과음 규격

| 이벤트 | 합성 | 길이 | 감각·BGM 관계 |
|---|---|---:|---|
| 1차 점프 | triangle 294→440Hz + sine 440→659Hz | 180ms | 가볍게 올라가며 박을 가리지 않음 |
| 2차 점프 | triangle 370→554Hz + 짧은 air noise | 155ms | 1차보다 높고 짧게, 두 번 눌렀음이 명확함 |
| 코인 | square 880Hz → triangle 1175Hz | 150ms | 16분음표 두 음, BGM A/C 계열 |
| 먹이 | triangle 220→330Hz + sine 330→440Hz | 240ms | 코인보다 따뜻하고 길게 |
| 불 공격 | saw 220→82Hz + band-pass noise 2100→620Hz + 고역 crackle 3회 | 300ms | 불타는 `화르륵` 소리. 공격 버튼 입력 즉시 재생 |
| 얼음 공격 | triangle 1319→880Hz + sine 1760→1175Hz + high-pass noise | 280ms | 유리결정 `챙` + 얼음 분산 `샤락` |
| 일반 적 명중 | saw 131→55Hz + low-pass noise 950→260Hz | 160ms | 불/얼음 발사음 뒤에 실제 명중 확인 |
| 피격 | square 146→73Hz + low-pass thud | 220ms | 화면 붉은 플래시와 동시, 짧게 음정 하강 |
| 체크포인트 | triangle A5-C6-E6 | 320ms | 3음 상승, BGM을 2dB 줄임 |
| 보스 충격파 | saw 98→49Hz + square 147→55Hz + low-pass noise | 420ms | 발사 시점에 웅직하게, 접근 효과는 입자로 표시 |
| 보스 피격 | low drum + 220Hz metallic click | 190ms | 일반 적과 다른 무거운 응답 |
| 보스 패배 | A3-C4-E4-A4 arpeggio + wind fade | 900ms | 곰의 0.9초 페이드아웃과 동기화 |
| 체력 0 / 부활 | 196→98Hz 하강 후 294→440Hz 상승 | 620ms | 실패와 체크포인 복귀를 하나의 구절로 표현 |

## 5. 구현 계약

- 최초 `start(element)`에서 오디오 초기화 후 시작 효과음과 BGM을 스케줄링합니다.
- 게임 코어는 `jump`, `double-jump`, `coin`, `food`, `attack-fire`, `attack-ice`, `enemy-hit`, `player-hit`, `checkpoint`, `boss-shot`, `boss-hit`, `boss-defeat`, `respawn`, `stage-clear`, `victory`만 방출합니다. 오디오 모듈이 이벤트를 받아 재생하여 게임 규칙과 소리 구현을 분리합니다.
- 화면을 벗어나거나 일시정지하면 새로운 효과음 생성을 멈추고, 계속하기 시 오래된 이벤트를 재생하지 않습니다.
- 동시 효과음은 8개로 제한하고, 같은 코인 소리는 45ms 안에 중복 스타트하지 않습니다.
- 오디오 기능을 지원하지 않는 브라우저에서는 소리만 생략하고 게임은 정상 진행합니다.

## 6. 음향 검수 항목

- 게임 시작을 눌러야 BGM이 시작되며, iOS/Android에서도 첫 입력 후 소리가 난다.
- 코인, 먹이, 1차 점프, 2차 점프, 피격은 서로 구분된다.
- 불 공격은 불타는 소리, 얼음 공격은 정결·빙결 소리로 즉시 구분된다.
- 공격하는 순간의 발사음과 적에 맞는 순간의 명중음이 둘 다 나며, 같은 효과음이 아니다.
- 음소거, 음량 변경, 일시정지, 처음부터 다시 시작 후에 중첩 BGM이 생기지 않는다.
