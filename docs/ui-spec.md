# SNOWCUB RUN — 화면·조작 명세

> 범위: UI는 총괄 Agent가 전달하는 게임 상태를 표시하고 사용자 입력을 명령으로 반환한다. 체력, 점수, 충돌, 스테이지 전환 규칙은 UI에서 임의로 변경하지 않는다.

## 1. 핵심 방향

- 레트로 픽셀 게임의 감성은 유지하되, 읽어야 하는 한글은 시스템 고딕체로 또렷하게 표시한다.
- 시작 화면의 핵심 행동은 “불/얼음 선택 → 게임 시작” 하나이다.
- 게임 중 HUD는 `체력(왼쪽) / 점수(정중앙) / 스테이지·거리(오른쪽)`로 고정한다.
- 조작 안내와 터치 버튼은 “점프”와 “공격”을 서로 다른 카드/영역으로 나눈다.
- 불과 얼음은 색상·연출·효과음만 다르고 성능 차이는 없다. 선택 카드에 이 사실을 명시한다.
- 시각 효과를 줄여도 게임 규칙과 리듬은 변하지 않도록 한다.

## 2. 화면 상태와 연결

| 게임 상태 | 화면에 보이는 것 | 사용자 행동 | UI가 반환할 명령 |
|---|---|---|---|
| `element-select` | 타이틀, 불/얼음 선택, 조작 미리보기, 설정 | 속성 선택, 시작 | `SELECT_ELEMENT`, `START_GAME`, `OPEN_SETTINGS` |
| `countdown` | 전체 화면 카운트 3·2·1 | 조작 잠김 | 없음 |
| `running` | 플레이 필드, HUD, 일시정지, 조작 버튼 | 점프, 2단 점프, 공격, 일시정지 | `JUMP`, `ATTACK`, `PAUSE` |
| `paused` | 어두운 배경 + 일시정지 패널 | 계속, 처음부터, 설정, 종료 | `RESUME`, `RESTART_TO_SELECT`, `OPEN_SETTINGS`, `QUIT_TO_TITLE` |
| `settings` | 음량, 소리 켜기, 모션 줄이기 | 값 변경, 뒤로 | `SET_VOLUME`, `SET_MUTED`, `SET_REDUCED_MOTION`, `CLOSE_SETTINGS` |
| `respawning` | 최근 체크포인트에서 부활 안내 | 조작 잠김 | 없음 |
| `stage-clear` | 현재 스테이지 요약, 다음 스테이지 | 다음 스테이지 시작 | `NEXT_STAGE` |
| `game-clear` | 최종 점수, 획득 코인/먹이, 보스 완료 | 다시 하기, 시작 화면 | `RESTART_TO_SELECT`, `QUIT_TO_TITLE` |
| `game-over` | 종료 이유, 최종 점수 | 다시 하기, 시작 화면 | `RESTART_TO_SELECT`, `QUIT_TO_TITLE` |

### 추천 상태 객체

```text
uiState = {
  mode, element, stage, stageName,
  hp, maxHp, score, distance, stageLength, checkpoint,
  coins, foods, jumpsRemaining,
  volume, muted, reducedMotion,
  bossVisible, bossHp, bossMaxHp,
  resultReason
}
```

- `hp`, `score`, `distance` 등은 핵심 로직의 결과를 그대로 받아 표시한다.
- `mode` 변경 시에만 대화상자 열기, 포커스 이동, 안내 음성을 처리한다.
- 점수가 매 프레임 바뀌어도 화면 낭독기에 매번 알리지 않고, 코인/먹이 획득·체크포인트·피격 같은 사건만 별도 `aria-live="polite"` 영역에 알린다.

## 3. 화면별 구조

### A. 시작·속성 선택

1. 게임 로고와 한 줄 설명
2. 속성 선택 카드 2개
   - 불: 불꽃 자산 + 붉은 외광, `aria-pressed`
   - 얼음: 얼음 자산 + 파란 외광, `aria-pressed`
   - 공통 문구: “성능은 같고 공격 연출과 효과음만 달라요.”
3. 조작 미리보기: 점프/공격을 좌·우 카드로 분리
4. “게임 시작” 버튼: 속성 선택 전에는 `disabled`
5. 설정 버튼: 텍스트를 함께 보이게 제공

### B. 플레이 화면

- 상단 HUD
  - 왼쪽: `체력 4/5` + 5칸 게이지. 색상만으로 체력을 구분하지 않는다.
  - 중앙: `SCORE` 라벨 + 6자리 점수. CSS 그리드의 중앙 칸에 놓아 좌·우 내용 길이와 무관하게 정중앙을 유지한다.
  - 오른쪽: `STAGE 2/3`, `420 / 800m`.
  - 보스 전투 중: HUD 아래에 고정 너비의 곰 체력바 추가.
- 우상단 일시정지 버튼: 44×44px 이상, 텍스트 대체 제공.
- 아래 조작
  - 데스크톱: 왼쪽 “점프” 카드, 오른쪽 “공격” 카드.
  - 모바일: 화면 아래 왼쪽 `점프`, 오른쪽 `공격` 버튼. 두 버튼 사이 12px 이상.
  - 점프 버튼 안에 “두 번 누르면 2단 점프”를 고정 표시.
- 코인·먹이·피격 점수는 캐릭터 근처 플로팅 텍스트로 500~700ms 표시한다. 모션 줄이기에서는 이동 없이 짧게 사라진다.

### C. 일시정지

- 제목: “잠깐 쉬어갈까요?”
- 주 버튼: `계속하기`
- 보조 버튼: `처음부터 다시 하기`
  - 버튼 아래에 “불·얼음 선택 화면으로 돌아갑니다.” 표시
- 보조 버튼: `설정`
- 마지막 링크형 버튼: `게임 종료`
- 대화상자가 열리면 “계속하기”로 포커스를 옮기고, 닫힌 후에는 일시정지 버튼 또는 게임 캔버스로 돌린다.

### D. 설정

- 음량: `0~100` 범위 입력 + 현재 값 텍스트.
- 소리 켜기: 토글 버튼. 이전 음량을 보존한다.
- 모션 줄이기: 시스템 `prefers-reduced-motion` 값을 초기값으로 쓰되, 사용자가 게임 내에서 변경할 수 있게 한다.
- 설정은 새로고침 후에도 보존하되 게임 점수/진행 상태와는 분리한다.

### E. 결과

- 스테이지 클리어: 스테이지 점수, 획득 수, 잔여 체력 → `다음 스테이지`.
- 전체 클리어: 최종 점수, 코인/먹이, 보스 격파 → `다시 모험하기`(속성 선택으로 돌아감), `게임 종료`.
- 게임 오버: 이유를 짧게 명시. 단, 체력 0이 체크포인트 부활 규칙이라면 일반 피격 상황에서는 게임 오버를 표시하지 않는다.

## 4. 조작 매핑

| 행동 | 키보드 | 터치 | 주의점 |
|---|---|---|---|
| 점프 | `Space`, `W`, `↑` | 왼쪽 `점프` | 공중에서 한 번 더 누르면 2단 점프. `keydown` 반복 입력은 무시. |
| 공격 | `J`, `X` | 오른쪽 `공격` | 불/얼음에 따라 연출·소리만 변경. |
| 일시정지/계속 | `P`, `Esc` | 우상단 `일시정지` | 시작/결과 화면에서는 일시정지 없음. |
| 소리 켜기 | `M` | 설정 토글 | 이전 음량 복원. |
| 선택/확인 | `Tab`, `Enter` | 해당 버튼 | 포커스 순서는 시각 순서와 같게. |

## 5. 반응형 규칙

- 기준 확인 크기: 320, 375, 768, 1024, 1440px.
- 768px 이상: 게임 필드 아래에 키보드 조작 카드를 보이고 터치 버튼은 숨김.
- 767px 이하: 키보드 카드를 숨기고 터치 버튼을 보임. `padding-bottom: env(safe-area-inset-bottom)` 반영.
- 가로 모드에서 HUD와 터치 버튼이 게임 핵심 구역을 덮지 않게 플레이 필드에 안전 여백을 둔다.
- 최소 터치 영역 48×48px, 주 조작 버튼은 높이 64px 이상.
- 작은 화면에서도 가로 스크롤이 생기지 않도록 한다.

## 6. 접근성·피드백

- 일반 텍스트 대비 4.5:1, 버튼 경계/아이콘 3:1 이상.
- 모든 버튼은 표준 `<button>`을 사용하고 `:focus-visible` 외곽선을 제거하지 않는다.
- 속성 선택은 색상 + 체크 표시 + `aria-pressed` 상태를 함께 사용한다.
- 게임 플레이 필드는 시각적으로는 `canvas`이지만, 화면 낭독기에는 “자동으로 달리는 백사자 런 게임”으로 요약한다.
- 소리만으로 성공/실패를 알리지 않고, 짧은 텍스트/색 변화/입자 효과를 함께 제공한다.
- `prefers-reduced-motion: reduce` 또는 설정의 모션 줄이기가 켜지면 화면 흔들림, 플로팅 이동, 반짝임을 제거하고 즉시 최종 상태를 표시한다.
- 대화상자와 패널은 배경과 명확히 분리되는 불투명 어두운 배경을 사용한다.

## 8. 통합 체크리스트

- [ ] 점수가 실제 화면 정중앙에 유지된다.
- [ ] 체력 5칸이 텍스트 `5/5`와 함께 표시된다.
- [ ] 점프와 공격 안내가 서로 다른 영역이다.
- [ ] 점프 영역에 2단 점프 안내가 항상 보인다.
- [ ] 처음부터 다시 하기가 속성 선택으로 돌아간다.
- [ ] `Esc`/`P` 일시정지와 포커스 복원이 정상 동작한다.
- [ ] 모바일 버튼이 안전 영역을 침범하지 않고 48px 이상이다.
- [ ] 속성 선택·피격·일시정지·결과가 색상만으로 구분되지 않는다.
- [ ] 모션 줄이기 설정을 모든 비필수 효과가 준수한다.
