## 모바일 수정 전후

수정 전 320px 화면에서는 `.arcade` 안쪽 폭이 298px인데 `.viewport`가 520px로 늘어나 오른쪽 222px가 잘렸다. 수정 후에는 `.viewport`가 298px로 맞춰졌고 문서 가로 폭도 320px로 유지됐다.

320px 측정:

- 문서: 320 / 320px
- arcade: 300px
- viewport: 298px
- 시작 버튼: x=44~276px
- 얼음 선택 카드: x=164~276px
- 점수 패널: x=171~299px
- 점프 버튼: x=21~155px
- 공격 버튼: x=165~299px

390px 측정:

- 문서: 390 / 390px
- arcade: 370px
- viewport: 368px
- 시작 버튼: x=44~346px
- 얼음 선택 카드: x=199~346px
- 점수 패널: x=241~369px
- 점프 버튼: x=21~190px
- 공격 버튼: x=200~369px

작은 화면에서는 속성 선택 패널이 게임 영역 안에서 세로로 스크롤될 수 있다. 모든 항목은 키보드와 터치로 접근 가능하며 가로로 숨는 항목은 없다. 공개를 막는 문제는 아니다.

## 보스 정렬

원본 스프라이트와 실제 그리기 좌표를 사용해 불투명 픽셀 최하단을 다시 계산했다.

- 논리 지면: y=396
- 곰 4개 프레임: 모두 y=393
- 백사자 안정 달리기 프레임: y=392.63, y=392.86
- 곰과 백사자 차이: 0.14~0.37px

허용 기준 2px 이내이며, 화면 이미지에서도 곰이 지면 아래로 잠기지 않고 백사자와 같은 선에 서 있다.
