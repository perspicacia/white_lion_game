# 백사자의 불과 얼음 모험 · Reborn

귀여운 아기 백사자를 조작해 사막, 붉은 신전, 태양의 밀림을 달리는 3스테이지 레트로 웹 런게임입니다. 캐릭터는 자동으로 달리며 플레이어는 점프와 공격 타이밍을 결정해 장애물과 악당을 돌파합니다.

## 게임 플레이

- 게임 시작 시 `불꽃의 힘` 또는 `서리의 힘`을 선택합니다.
- 두 속성의 성능은 같으며 공격 연출과 효과음만 다릅니다.
- 돌·문턱·가시는 점프 또는 2단 점프로 피합니다.
- 하이에나와 유령은 불꽃 또는 얼음 공격으로 물리칩니다.
- 체력은 5칸이며 피격될 때마다 1칸 감소합니다.
- 체력이 모두 소진되면 최근 500m 체크포인트에서 다시 시작합니다. 최종 보스전 시작 지점도 별도로 저장합니다.
- 코인과 먹이는 가장 높이 점프했을 때 수집할 수 있는 위치에 나타납니다.
- 치킨과 스테이크는 120점과 체력 1칸을 회복합니다.

## 스테이지

### 1. 황금빛 사막

바위, 문턱, 가시와 하이에나가 등장하는 첫 번째 코스입니다. 빠르고 용맹한 전진 리듬의 배경음이 재생됩니다.

### 2. 붉은 신전

유령과 혼합 장애물이 더 촘촘하게 등장합니다. 웅장한 행진과 화려한 픽셀 장식음으로 신전 분위기를 표현했습니다.

### 3. 태양의 밀림

가장 빠르고 어려운 코스입니다. 손북과 나무 타악기 중심의 배경음이 재생되며 마지막에는 거대 곰 보스가 등장합니다.

거대 곰은 체력 20을 가지고 있으며, 백사자 몸통 중앙을 향해 직선 공격을 발사합니다. 보스를 물리치면 곰은 바닥으로 떨어지지 않고 제자리에서 서서히 사라집니다.

| 2단 점프 | 공중에서 점프 키 한 번 더 | 공중에서 `점프` 버튼 한 번 더 |
